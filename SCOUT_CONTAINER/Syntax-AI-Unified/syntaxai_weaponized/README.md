## What is this?

Every developer talks to AI assistants daily. But those conversations disappear. **SyntaxAI Weaponized** captures your AI chats, extracts the code, organizes it by language, and builds a searchable library - **automatically**.

Built in 3 hours using AI itself. Part of the larger [BleakDev](../BleakDev) ecosystem.

## ✨ Features

- 🚗 **Background Clipboard Monitor** - Captures everything you copy
- 🧠 **Smart Code Extraction** - Separates vibe from code blocks
- 📁 **Language-Aware Organization** - Python, Bash, JSON, YAML support
- 🔨 **Optional Execution** - Run extracted code safely
- 📊 **Stats Dashboard** - Track your capture productivity
- 🎯 **Zero Configuration** - Works out of the box
