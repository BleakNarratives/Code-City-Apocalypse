5. CODE OPTIMIZATION ("BITCH WORK" PROTOCOL)
================================================================================

5.1 RUNNING OPTIMIZATION
------------------------
# Analysis only (safe, no changes):
python -m src.python.optimizers.code_optimizer --scan-only

# Apply auto-fixes (creates .py.bak backups):
python -m src.python.optimizers.code_optimizer --auto-fix

# Full scan with report:
python -m src.python.optimizers.code_optimizer --scan-only --report


5.2 OPTIMIZATION RULES
----------------------
Enabled by default:
  ✓ Long functions (>50 lines) - FLAGGED
  ✓ Missing docstrings - FLAGGED
  ✓ Unused imports - FLAGGED
  ✓ Print statements - AUTO-FIXED (converted to logging)
  ✓ Magic numbers - FLAGGED
  ✓ Missing type hints - FLAGGED

To customize rules:
  Edit OPTIMIZATION_RULES in .env
  Example: OPTIMIZATION_RULES={"long_functions": 100, "missing_docstrings": false}


5.3 PATTERN JOURNAL
--------------------
All optimizations are logged to: pattern_journal.json

Each entry contains:
  - Timestamp
  - File analyzed
  - Issues found
  - Fixes applied
  - Confidence score

To view journal:
  cat pattern_journal.json | python -m json.tool

To clear journal:
  > pattern_journal.json.bak && cat /dev/null > pattern_journal.json

8. TROUBLESHOOTING
================================================================================

8.1 COMMON ISSUES
-----------------

ISSUE: Nexus API not responding
  - Check if Nexus API is running: ps aux | grep nexus_api
  - Check port: netstat -tuln | grep 8000
  - Restart: python -m src.python.services.nexus_api

ISSUE: Code not being extracted from chat
  - Verify CaptCoder is running: ps aux | grep captcoder
  - Check input format (must use backticks for code blocks)
  - Enable debug logging: add --debug flag

ISSUE: Auto code extractor not finding files
  - Check watched directories exist: ls /storage/emulated/0/Download
  - Verify permissions: ls -la /storage/emulated/0/Download
  - Check .env MONITOR_DIRECTORIES setting

ISSUE: TypeScript frontend not loading
  - Verify Node dependencies: npm list
  - Reinstall: rm -rf node_modules/ && npm install
  - Check Vite config: cat vite.config.ts

ISSUE: Pattern Journal not being updated
  - Check write permissions: touch pattern_journal.json
  - Verify disk space: df -h
  - Check for errors: tail -n 50 logs/optimizer.log


8.2 ERROR CODES
---------------

ERROR: NEXUS_CONNECTION_FAILED
  - Nexus API is down or unreachable
  - Action: Start Nexus API or check network

ERROR: NO_CODE_BLOCKS_FOUND
  - Input doesn't contain valid code blocks
  - Action: Use backticks (```) around code

ERROR: PERMISSION_DENIED
  - File/directory access denied
  - Action: Check permissions, run as admin if needed

ERROR: OCR_NOT_INSTALLED
  - Tesseract OCR not available
  - Action: pip install pytesseract && apt install tesseract-ocr

ERROR: TTS_NOT_AVAILABLE
  - Text-to-speech engine not found
  - Action: apt install espeak || brew install espeak


8.3 LOG FILES

Main log files:

10. SECURITY
================================================================================

10.1 SENSITIVE DATA
-------------------
Never commit to version control:
  - .env (contains API keys, credentials)
  - *.bak files (may contain sensitive code)
  - logs/*.log (may contain user data)
  - generated_code/* (may contain proprietary code)

Add to .gitignore:
  .env
  *.bak
  logs/
  generated_code/
  auto_extracted_code/
  pattern_journal.json


10.2 PERMISSIONS
----------------

Minimum permissions required:
  - Read: Monitored directories, code files
  - Write: Output directories, logs, pattern journal
  - Execute: Scripts, Python/Node binaries

Recommended permissions:
  chmod 755 scripts/*.sh
  chmod 755 src/
  chmod 644 .env
  chmod 600 logs/*.log


10.3 API SECURITY
----------------

Nexus API security:
  - Enable authentication: NEXUS_AUTH_ENABLED=True
  - Set API key: NEXUS_API_KEY=your_secure_key
  - Restrict origins: NEXUS_CORS_ORIGINS=http://localhost:3000,http://127.0.0.1:5173

TLS/SSL:
  - Use HTTPS for production: NEXUS_HTTPS=True
  - Provide cert files: NEXUS_SSL_CERT=/path/to/cert.pem
  - Provide key file: NEXUS_SSL_KEY=/path/to/key.pem


10.4 NETWORK SECURITY
----------------------

Firewall rules (if applicable):
  - Allow: 127.0.0.1:8000 (Nexus API)
  - Allow: 0.0.0.0:3000 (Frontend)
  - Allow: Livestream endpoints

Restrict inbound connections:
  - Bind to 127.0.0.1 for local-only access
  - Use firewall to block external access to dev ports
